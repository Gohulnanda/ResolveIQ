## Summary
Email does not arrive or send, Outlook shows disconnected, the mailbox quota is exceeded, or a shared mailbox or calendar is missing.

## Symptoms
The status bar shows disconnected or trying to connect. Messages stay in the outbox. Large attachments bounce. The user is told the mailbox is full. A shared mailbox vanished, or calendar items do not sync to the phone.

## Likely causes
- No network connection or Work Offline mode turned on.
- A damaged Outlook profile or a stale cached mailbox.
- A mailbox over its size quota or an attachment over the size limit.
- A changed password prompting repeated credential requests.

## Resolution steps
1. Check that you have network access and that Work Offline is not enabled in Outlook.
2. Open webmail in a browser; if mail works there, the problem is in the desktop profile.
3. Restart Outlook, then create a new Outlook profile if the status stays disconnected.
4. For a full mailbox, empty Deleted Items, archive old mail and remove large attachments.
5. Share large files through a cloud link instead of attaching them.
6. For a missing shared mailbox or calendar, ask for the permission to be confirmed and re-add it to the profile.

## Escalate when
Many users cannot send or receive, mail is delayed for hours, or messages from a trusted sender are repeatedly marked as spam.
