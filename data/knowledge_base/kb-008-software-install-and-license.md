## Summary
A program cannot be installed or updated, or it refuses to start because of a licence problem.

## Symptoms
The installer ends with an error code such as 1603. The software center shows a failed deployment. The application reports an expired, invalid or already-used license key.

## Likely causes
- A previous half-installed version blocking the new one.
- Insufficient disk space or pending restart.
- The license pool is exhausted or the key has expired.
- Missing administrator rights for the installation.

## Resolution steps
1. Restart the computer to clear any pending update, then retry the installation from the software center.
2. Confirm there is enough free disk space and that no other installer is running.
3. Uninstall any old or partial version of the program and install again.
4. For a license message, record the exact wording and the product version shown in the About dialog.
5. Sign out and back in to the application so it refreshes the assigned license.
6. If the software is not in the catalog, submit a software request with the business reason and manager approval.

## Escalate when
The licence pool is exhausted, a key shows as used on another machine, or the deployment fails for many computers.
