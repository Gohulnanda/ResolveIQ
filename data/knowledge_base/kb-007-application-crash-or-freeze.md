## Summary
A desktop application closes unexpectedly, stops responding, or the whole computer becomes slow.

## Symptoms
A program shows not responding and then closes without saving. It crashes immediately after launch or after a recent update. Everything opens slowly and the fan runs constantly.

## Likely causes
- A faulty update or a corrupted application profile.
- A faulty add-in or extension.
- A very large or damaged file.
- A background process using high CPU or memory.

## Resolution steps
1. Note the exact error message and whether it started after an update or opening a particular file.
2. Restart the computer, then open the application in safe mode, which loads it without add-ins.
3. Disable add-ins and extensions one at a time to find the one causing the crash.
4. Open Task Manager and check for a process using most of the CPU or memory, then end it if it is not needed.
5. Use the repair option of the application from the installed apps list, and reinstall it from the software center if repair does not help.
6. Free at least a few gigabytes of disk space and install pending system updates.

## Escalate when
The crash affects many users after a rollout, data was lost, or the application fails after a reinstall.
