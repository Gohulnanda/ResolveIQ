## Summary
Wireless connections drop, video calls freeze or pages load slowly in the office.

## Symptoms
The laptop disconnects from the corporate wireless network every few minutes. Pages and file transfers are very slow. Colleagues in the same area report the same behaviour.

## Likely causes
- Weak signal or a congested access point in a crowded area.
- A stale saved wireless profile or outdated wireless driver.
- Power-saving settings turning off the wireless adapter.
- A faulty access point or uplink switch port.

## Resolution steps
1. Check whether neighbours in the same area are affected, since that points to an access point problem rather than the laptop.
2. Toggle Wi-Fi off and on, then forget the corporate network and reconnect with your credentials.
3. Move to a spot with a stronger signal, or plug in an ethernet cable to compare speed.
4. Disable the adapter option that lets the computer turn the device off to save power.
5. Install the latest wireless driver from the software center and restart.
6. Run a ping to the default gateway for one minute and note any packet loss for the ticket.

## Escalate when
Many users in one area are affected, packet loss to the gateway exceeds a few percent, or the problem started after a network change.
